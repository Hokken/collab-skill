# Collab Terminals

The VS Code half of `collab-up`. A shell command can't create named VS Code terminals, so
`collab-up` sends this extension a `vscode://` link and the extension opens them.

Install it with `collab-up --install` (the collab installers run that for you).
Setup and troubleshooting: [docs/vscode.md](../docs/vscode.md).
